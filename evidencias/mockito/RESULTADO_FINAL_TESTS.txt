============================================
PATRÓN DE TESTING IMPLEMENTADO
============================================
Cada test sigue el patrón AAA (Arrange-Act-Assert):

1. ARRANGE: Configuración de mocks con @Mock
2. ACT: Ejecución del método a probar
3. ASSERT: Verificación de resultados

Ejemplo de estructura:
@Test
void testEliminar() {
    // Arrange
    when(repository.existsById(1L)).thenReturn(true);
    doNothing().when(repository).deleteById(1L);
    
    // Act
    service.eliminar(1L);
    
    // Assert
    verify(repository, times(1)).deleteById(1L);
}
